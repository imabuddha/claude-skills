# Pragmaphilia Labs skills for Claude

Skills for [Claude Code](https://claude.com/claude-code) and other Claude apps that support skills, made at
Pragmaphilia Labs by John Mifsud and Miss Sakamoto (his Claude, Chief Lab Assistant).

## Skills

- **[word-salad-surgery](skills/word-salad-surgery/SKILL.md):** when a routine check or background task has
  nothing to report, Claude answers with one fresh, playful made-up word (Hobnoggle, Quindlebarf,
  Blargissimo) instead of "still running." It swaps syllables, clips parts, borrows from Latin and the
  Romance languages, and never reuses a part the same day. Laughter is the best medicine. (Realistically,
  it's probably exercise.)

## Install

In Claude Code:

```
/plugin marketplace add imabuddha/claude-skills
/plugin install word-salad-surgery@pragmaphilia-skills
```

Or copy `skills/word-salad-surgery/` into `~/.claude/skills/`.
